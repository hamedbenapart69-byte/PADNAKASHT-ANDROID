# پادناکِشت — نسخه عملیاتی اولیه

## اجرا
فایل `index.html` را با مرورگر به‌روز روی ویندوز باز کنید. در گوشی اندرویدی نیز می‌توانید فایل را از طریق یک میزبان وب محلی/سایت HTTPS باز کنید؛ برای استفاده پایدار روی گوشی، انتشار روی HTTPS پیشنهاد می‌شود.

## امکانات پیاده‌سازی‌شده
- رابط فارسی و راست‌چین، واکنش‌گرا
- مشتریان: ثبت، ویرایش، جست‌وجو، جلوگیری از شماره تلفن تکراری، پرونده و مانده
- محصولات: ثبت و ویرایش، قیمت خرید/فروش، موجودی و ثبت ورود/خروج با علت
- فاکتور چندقلمی با محاسبه ردیف‌ها، تخفیف، کنترل موجودی، سررسید، نمایش مانده، چاپ از طریق مرورگر
- دریافت/پرداخت و اتصال دریافت به فاکتور، کنترل سقف دریافت نسبت به مانده
- داشبورد و گزارش‌های اولیه از داده واقعی، فاکتورهای معوق و کم‌موجودی
- خروجی CSV و پشتیبان‌گیری/بازیابی JSON
- ذخیره‌سازی محلی در مرورگر

## محدودیت‌های مهم
- این نسخه یک برنامه وب محلی است، نه APK اندروید یا بسته نصب ویندوز.
- داده‌ها در مرورگر همان دستگاه ذخیره می‌شوند؛ پاک‌کردن داده‌های مرورگر ممکن است اطلاعات را حذف کند. تهیه نسخه پشتیبان ضروری است.
- همگام‌سازی بین دستگاه‌ها، ورود کاربران/سطوح دسترسی، ذخیره ابری، پیامک، فایل PDF مستقل، پیوست تصویر محصول، ویرایش/برگشت تراکنش با دفترکل حسابداری کامل هنوز پیاده‌سازی نشده‌اند.
- لغو فاکتور دارای تراکنش مالی عمداً متوقف می‌شود تا بدون فرایند برگشت مالی، سوابق خراب نشوند.
- داده آزمایشی به‌صورت پیش‌فرض وجود ندارد؛ اعداد داشبورد از داده ثبت‌شده به دست می‌آیند.
- این خروجی پیش‌نمونه‌ای عملیاتی برای شروع و ارزیابی است و پیش از استفاده مالی واقعی، باید آزمون‌های تکمیلی و بازبینی حسابداری/امنیتی انجام شود.

## نکته نگهداری
تمام داده‌ها در فضای ذخیره‌سازی مرورگر با کلید محلی نسخه برنامه نگهداری می‌شوند. پشتیبان JSON را در محل امن نگه دارید.
